# PHOTO BRAWL V28 — Pausa entre ejercicios

Al cumplir el objetivo de una lección, la Escuela Arcade conserva el ejercicio visible 2 segundos adicionales antes de preparar el siguiente. Muestra el mensaje «¡BIEN HECHO! · SIGUIENTE EN 2 S». Durante ese tiempo no vuelve a comprobar el objetivo ni dispara transiciones repetidas. «SALTAR PASO» y «REPETIR» cancelan el estado de espera.

No afecta a los combates normales ni a las reglas del servidor.

# PHOTO BRAWL V34 · Combate móvil vertical

Cambios exclusivos para orientación portrait:

- Se oculta el panel de consejos «APRENDE EN 10 SEGUNDOS» para liberar el centro de pantalla.
- El HUD completo (retratos, vida, energía, reloj y pausa) ocupa una franja separada encima de la imagen de combate; se reserva altura antes de dibujar la arena.
- La arena comienza debajo del HUD y mantiene su relación 16:9 y colisiones intactas.
- El botón SÚPER permanece condicionado a tener la energía llena, pero se centra por encima del conjunto derecho de cuatro controles sin taparlos.
- Se conserva el joystick y se mantiene el debug de colisiones exclusivamente en Training.
- No se altera el diseño de juego horizontal ni los cálculos de físicas o del servidor.

Despliegue: solo frontend (Vercel). Sin migraciones SQL ni cambios de Render.
